# VEXTRALOOM Documentation

## Project Overview
VEXTRALOOM is a premium futuristic career operating system for students built on the MERN stack (MongoDB, Express, React, Node.js) with TypeScript.

## Repository Structure
```
VextraLoom/
├── client/          # Frontend application (React + Vite + TypeScript)
├── server/          # Backend API (Node.js + Express + TypeScript)
├── docs/            # Architecture and system documentation
├── .gitignore       # Repository security and exclusion rules
├── .env.example     # Environment variable template
└── README.md        # Getting started and setup guide
```

## Technology Stack
- **Frontend**: React 18/19, Vite, TypeScript, React Router
- **Backend**: Node.js, Express, TypeScript
- **Database**: MongoDB Atlas (Target Database: `vextraloom`)
- **API Standard**: RESTful JSON API
